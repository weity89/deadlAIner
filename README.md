**deadlAIner** — умный Telegram-бот, который спасает от прокрастинации. Он превращает хаотичные сообщения в структурированные задачи, оценивает время на их выполнение с помощью GigaChat и напоминает о начале работы.

> 🧪 **Текущий статус: Beta 0.0.3**
> Продукт находится в активной разработке. Мы тестируем парсинг дедлайнов и RAG-систему для уточнения задач по условию.

## 🎯 Проблема
Студенты срывают дедлайны не потому, что забывают, а потому что не умеют оценивать сложность задач и начинают слишком поздно.

## 💡 Решение
Просто напиши боту: *"Лаба по ООП до пятницы"* — и он:
1. Выделит суть задачи и **дату** дедлайна.
2. Оценит сложность (например, 8 часов).
3. Разобьет на этапы.
4. Напомнит, когда пора начинать.

## ✨ Фичи (Beta 0.0.3)
- [x] Парсинг естественного языка (NLP) через GigaChat.
- [x] Оценка времени и декомпозиция задач.
- [x] Распознавание дат («до пятницы» -> конкретное число).
- [x] `/list` — список всех задач с дедлайнами.
- [x] `/info <номер> <текст>` — уточнение задачи по условию (RAG). Бот переоценит время, если задача сложнее, чем казалось.
- [x] `/busy` — указание времени, когда ты занят (сон/учеба).
- [x] Работа **без VPN** благодаря интеграции с Cloudflare Workers (`andro-cfw`).

## 🛠 Стек
- Python 3.9+
- Aiogram 3
- GigaChat API (Sber)
- APScheduler
- Cloudflare Workers (через `andro-cfw`)

## ⚙️ Запуск
```bash
git clone https://github.com/weity89/deadlAIner.git
cd deadlAIner
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Создай .env с ключами (см. .env.example)
python main.py
```

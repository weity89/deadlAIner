# 🤖 AI-Deadline Bot (MVP)

Telegram-бот, который превращает хаотичные сообщения в структурированные задачи, оценивает время на их выполнение с помощью YandexGPT и напоминает о начале работы.

## 🚀 Проблема
Студенты и фрилансеры прокрастинируют не потому, что забывают о дедлайнах, а потому что не умеют оценивать трудоемкость задач.

## 💡 Решение
Бот использует LLM (YandexGPT) для NLP-анализа текста. Он:
1. Парсит название задачи и дедлайн из обычного сообщения.
2. Оценивает сложность (например, "лаба по ООП" = 5 часов).
3. Разбивает задачу на этапы (декомпозиция).
4. Ставит таймеры и напоминает о начале работы.

## 🛠 Стек технологий
* Python 3.9+
* Aiogram 3 (Telegram Bot API)
* YandexGPT API (LLM)
* APScheduler (Планировщик задач)

## ⚙️ Как запустить локально
1. Клонируйте репозиторий:
   `git clone https://github.com/ваш_ник/ai-deadline-bot.git`
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Создайте файл `.env` и добавьте свои ключи:
   ```env
   TELEGRAM_TOKEN=ваш_токен
   YANDEX_API_KEY=ваш_ключ
   YANDEX_FOLDER_ID=ваш_id
4. Запустите бота
